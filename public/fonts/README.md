# Self-hosted fonts

These two Latin WOFF2 files are manually downloaded from Google Fonts, not installed through npm. They are requested at build time only; visitors load them from this site's own `/fonts` folder.

- `instrument-sans-latin.woff2`: [Google Fonts CSS endpoint](https://fonts.googleapis.com/css2?family=Instrument+Sans:wght@400;500;600;700&display=swap), resolved to `https://fonts.gstatic.com/s/instrumentsans/v4/pxiTypc9vsFDm051Uf6KVwgkfoSxQ0GsQv8ToedPibnr0SZe1Q.woff2`
- `newsreader-latin.woff2`: [Google Fonts CSS endpoint](https://fonts.googleapis.com/css2?family=Newsreader:opsz,wght@6..72,400;6..72,500&display=swap), resolved to `https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjA.woff2`

Both families are licensed under the SIL Open Font License 1.1. The copies of `OFL.txt` for each family are stored beside the font files as `OFL-Instrument-Sans.txt` and `OFL-Newsreader.txt`.
